# মানুষ - সেবা প্রদানকারী ও গ্রহণকারীদের জন্য প্ল্যাটফর্ম

## প্রকল্প বিবরণ

"মানুষ" হল ঢাকার সুত্রাপুর, গেন্ডারিয়া, যাত্রাবাড়ি এলাকার জন্য একটি অনলাইন সেবা প্ল্যাটফর্ম, যেখানে সেবা প্রদানকারী ও গ্রহণকারীরা সহজেই সংযোগ স্থাপন করতে পারেন। এই প্ল্যাটফর্মে বিভিন্ন ধরনের সেবা যেমন - ইলেকট্রিশিয়ান, প্লাম্বার, কার্পেন্টার, পেইন্টার, ক্লিনার ইত্যাদি পাওয়া যায়।

## ইনস্টলেশন নির্দেশাবলী

### প্রয়োজনীয় সফটওয়্যার
- Node.js (v14 বা উচ্চতর)
- MySQL (v5.7 বা উচ্চতর)

### ইনস্টলেশন ধাপসমূহ

1. **রিপোজিটরি ক্লোন করুন**
   ```
   git clone https://github.com/yourusername/manush-website.git
   cd manush-website
   ```

2. **ব্যাকএন্ড সেটআপ**
   ```
   cd backend
   npm install
   ```

3. **ডাটাবেস সেটআপ**
   - MySQL ডাটাবেস তৈরি করুন: `manush_db`
   - `.env` ফাইল কনফিগার করুন:
     ```
     DB_HOST=localhost
     DB_USER=root
     DB_PASSWORD=your_password
     DB_NAME=manush_db
     JWT_SECRET=your_jwt_secret
     JWT_EXPIRE=30d
     ```

4. **ব্যাকএন্ড সার্ভার চালু করুন**
   ```
   npm start
   ```
   সার্ভার পোর্ট 5000-এ চলবে।

5. **ফ্রন্টএন্ড সেটআপ**
   - `frontend` ফোল্ডারের ফাইলগুলি একটি ওয়েব সার্ভারে হোস্ট করুন (Apache, Nginx, ইত্যাদি)
   - বা ডেভেলপমেন্টের জন্য সহজ সার্ভার ব্যবহার করুন:
     ```
     cd frontend
     npx serve
     ```

## API ডকুমেন্টেশন

### অথেনটিকেশন API
- `POST /api/auth/register` - ইউজার রেজিস্ট্রেশন
- `POST /api/auth/login` - ইউজার লগইন
- `GET /api/auth/me` - কারেন্ট ইউজার ডাটা

### সার্ভিস API
- `GET /api/services` - সকল সার্ভিস
- `GET /api/services/:id` - একটি নির্দিষ্ট সার্ভিস
- `POST /api/services` - নতুন সার্ভিস তৈরি
- `PUT /api/services/:id` - সার্ভিস আপডেট
- `DELETE /api/services/:id` - সার্ভিস ডিলিট

### বুকিং API
- `GET /api/bookings` - সকল বুকিং
- `GET /api/bookings/:id` - একটি নির্দিষ্ট বুকিং
- `POST /api/bookings` - নতুন বুকিং তৈরি
- `PUT /api/bookings/:id` - বুকিং স্ট্যাটাস আপডেট
- `DELETE /api/bookings/:id` - বুকিং ক্যানসেল

### পেমেন্ট API
- `POST /api/payments` - নতুন পেমেন্ট তৈরি
- `GET /api/payments/booking/:bookingId` - বুকিং অনুযায়ী পেমেন্ট
- `POST /api/payments/bkash` - বিকাশ পেমেন্ট প্রসেস
- `POST /api/payments/nagad` - নগদ পেমেন্ট প্রসেস
